# GPT ドラゴン娘

白い髪、紫の瞳、淡い紫のドラゴンの翼を持つ、アニメーション付きの作業パートナーです。ユーザー提供のキャラクター参考画像をもとに、翼を少し広げて制作しました。9 種類の動作と 16 方向の視線を収録しています。

![動作プレビュー](previews/all-states.gif)

## ファイル

- `assets/spritesheet.png`：最終版の透過 PNG スプライトシート。この配置に対応した Pets のインポート手順で使用できます。
- `pet.json`：名前、説明、サイズ、動作順序、SHA-256。
- `previews/`：9 種類の動作、視線ループ、待機からジャンプへのつなぎ、全体の GIF/MP4、4 フレームの静止画デモ。
- `docs/contact-sheet.png`：全フレームのラベル付き一覧。
- `docs/direction-sheet.png`：16 方向の視線一覧。
- `validation/`：最終版の構造、品質、方向、背景除去の確認記録。
- `checksums.sha256`：パッケージ内ファイルの整合性チェックサム。

## スプライトシートの配置

v2 配置：1536 × 2288 px、8 列 × 11 行、1 セル 192 × 208 px。有効フレームは 73、未使用の 15 セルは透明です。各行は左から順に埋めています。

| 行（0 から開始） | 状態 | フレーム数 |
| --- | --- | ---: |
| 0 | idle / 待機 | 6 |
| 1 | running-right / 右へ移動 | 8 |
| 2 | running-left / 左へ移動 | 8 |
| 3 | waving / 手を振る | 4 |
| 4 | jumping / ジャンプ | 5 |
| 5 | failed / 失敗時の反応 | 8 |
| 6 | waiting / 応答待ち | 6 |
| 7 | running / 考えながら作業 | 6 |
| 8 | review / 結果を確認 | 6 |
| 9 | 視線 000° → 157.5° | 8 |
| 10 | 視線 180° → 337.5° | 8 |

視線は画面座標で定義し、000° は上、090° は右、180° は下、270° は左です。22.5° ごとに 1 フレーム、時計回りに並びます。

## 使い方

フォルダの内容を GitHub リポジトリのルートにアップロードします。この形式に対応するクライアントは `assets/spritesheet.png` を読み込みます。GitHub はファイルを保存・表示するだけで、ペットを自動インストールしたり選択したりしません。

## 制作と検証

内蔵の imagegen でキャラクターと個別の動作ストリップを生成し、Pets スキル付属のスクリプトでフレームの抽出、合成、背景除去、検証を行いました。最終版は v2 構造検証、品質確認、3 名の独立したレビュアーによる方向判定の多数決、Pets サービスの事前確認を通過しました。隣接する一部の斜め方向は姿勢の差が小さく、詳細は検証レポートに残しています。

アカウントのペット ID、アップロードセッション、一時ダウンロードリンク、ローカルの絶対パス、元の参考画像、採用しなかった中間版は含みません。レポート内の `workflow/` パスは制作段階の出典記録であり、中間ファイルが付属することを意味しません。
