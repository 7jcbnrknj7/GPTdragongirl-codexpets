# GPT龙娘

白发紫瞳、淡紫龙翼的动画工作伙伴。以用户提供的角色参考图为基础制作，翅膀稍微加宽，包含九种动作与十六个视线方向。

![动作预览](previews/all-states.gif)

## 文件

- `assets/spritesheet.png`：最终透明 PNG 精灵图，可用于支持该布局的 Pets 导入流程。
- `pet.json`：名称、描述、尺寸、动作顺序和 SHA-256。
- `previews/`：九种动作、视线循环、待机到跳跃过渡、完整动画 GIF/MP4，以及四帧静态演示。
- `docs/contact-sheet.png`：全部帧的带标签总览。
- `docs/direction-sheet.png`：十六个视线方向总览。
- `validation/`：最终结构、质量、方向和背景清理检查记录。
- `checksums.sha256`：包内文件的完整性校验。

## 精灵图布局

v2 布局：1536 × 2288 px；8 列 × 11 行；每格 192 × 208 px。共 73 个有效帧，15 个未使用格保持透明。每行从最左侧开始填充。

| 行（从 0 开始） | 状态 | 帧数 |
| --- | --- | ---: |
| 0 | idle / 待机 | 6 |
| 1 | running-right / 向右移动 | 8 |
| 2 | running-left / 向左移动 | 8 |
| 3 | waving / 挥手 | 4 |
| 4 | jumping / 跳跃 | 5 |
| 5 | failed / 失败反应 | 8 |
| 6 | waiting / 等待回应 | 6 |
| 7 | running / 思考工作 | 6 |
| 8 | review / 检查成果 | 6 |
| 9 | 000° → 157.5° 注视 | 8 |
| 10 | 180° → 337.5° 注视 | 8 |

视线以屏幕坐标定义，000° 为上，090° 为右，180° 为下，270° 为左，每 22.5° 一帧，按顺时针排列。

## 使用

将这个文件夹的内容上传到 GitHub 仓库根目录即可。支持此精灵图格式的客户端应读取 `assets/spritesheet.png`；GitHub 本身只存放与展示文件，不会自动安装或选中宠物。

## 验证与制作

使用内置 imagegen 生成角色和独立动作条，再用 Pets 技能附带脚本提取、合成、清理背景与验证。最终图已通过 v2 结构验证、质量检查、三位独立评审的方向多数判断，以及 Pets 服务预检。部分相邻斜向姿势的变化较细微，详情保留在验证报告中。

包中不包含账户宠物 ID、上传会话、临时下载链接、本机绝对路径、原始参考图或被弃用的中间版本。报告中的 `workflow/` 路径仅记录制作阶段来源，不表示这些中间文件随包提供。

## 许可

本项目尚未指定开源许可证。参考角色图由用户提供；此文件包不声明原参考图或角色的版权归属，也不自动授予再分发或商业使用许可。
